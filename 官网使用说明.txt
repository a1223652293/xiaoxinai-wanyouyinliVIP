小新AI官网 · 使用说明

一、这是什么

本目录是一套完整的静态官网，页面放在 index.html，
样式在 assets/css/site.css，交互在 assets/js/site.js，
软件图标与界面截图在 assets/img，买家安装包在 downloads。

二、本地预览

1. 在本目录打开终端。
2. 运行：node server.js
3. 浏览器打开：http://127.0.0.1:5179/

三、给别人访问

二维码会自动读取当前网页地址。别人能扫码的前提是：
把本目录内容发布到一个公开网址，例如 GitHub Pages、
腾讯云/阿里云静态托管、自己的服务器，或任意支持静态文件的空间。

发布步骤：
1. 上传 index.html、assets、downloads 整个目录。
2. 打开网站确认“下载完整买家包”按钮可以下载。
3. 在电脑浏览器打开官网，页面底部的二维码会自动指向官网地址，
   可保存二维码发到朋友圈、海报或宣传图。

四、替换安装包

方案 A：把新买家包重命名为：
downloads/小新AI万有引力买家包.zip
并替换原文件，页面无需改动。

方案 B：把安装包传到网盘/对象存储，得到直链后，
打开 assets/js/site-config.js，把 downloadUrl 改成直链。

五、文件太大传不上 GitHub 怎么办

GitHub 网页上传单个文件限 25MB，所以 75.8MB 的买家包
不能直接拖进仓库页面。正确做法是走 GitHub Releases：

1. 在 GitHub 打开你的仓库，进入 Releases。
2. 点 Create a new release，填写版本号，例如 v1.0.0。
3. 在 Attach binaries 里拖入“小新AI万有引力买家包.zip”
   （Releases 单文件最大 2GB）。
4. 发布后复制下载直链，格式类似：
   https://github.com/你的用户名/你的仓库/releases/download/v1.0.0/小新AI万有引力买家包.zip
5. 把这条链接填进 assets/js/site-config.js 的 downloadUrl。

部署 GitHub Pages 时只需上传 index.html 和 assets 目录，
downloads 目录可以不上传，避免网页仓库体积过大。

六、修改名称或文字

页面里所有“小新AI-万有引力魔法生图工坊”等文字都在 index.html 中，
可用记事本直接搜索修改；颜色与排版在 site.css。
